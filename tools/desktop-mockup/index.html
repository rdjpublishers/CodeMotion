Zip a static site → preview it in a MacBook → record the preview as a video

100% local CodeMotion

Drop a .zip of your static site

Unzipped in your browser with JSZip. Nothing is uploaded to any server.

or paste the zip — Ctrl+V
  • Include the whole site. Every index.html, folder, CSS file, font and image is read from the zip.
  • No server needed. Paths like /style.css, ./assets/img.png and ../css/app.css are rewritten to in-memory blob URLs.
  • Multi-page is fine. Clicking a link inside the mockup loads the next page from the zip, not from the internet.
